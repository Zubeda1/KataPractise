# Kata Practise

A collection of coding kata solutions written in TypeScript, practised from [Codewars](https://www.codewars.com/).

## Tech Stack

- TypeScript
- Jest (v29) for testing

## Project Structure

```
test/
├── utils/          # Kata solutions
└── *.test.ts       # Test files
```

## Katas

| Kata | Description |
|------|-------------|
| String Ends With | Check if a string ends with a given ending |
| Printer Error | Count characters past 'm' in a printer string |
| Shortest Word | Return the length of the shortest word in a string |
| Maskify | Mask all but the last 4 characters of a string with `#` |
| Square Every Digit | Square each digit of a number and concatenate the results |
| Add Binary | Add two numbers and return the result as a binary string |

## Getting Started

Install dependencies:

```bash
npm install
```

Run tests:

```bash
npm test
```
